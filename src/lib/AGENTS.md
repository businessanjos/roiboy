# AGENTS.md — src/lib

- Team numbers are never clients: `public.internal_client_split(p_account_id)` (SECURITY INVOKER over `zapp_internal_contacts` + `hr_collaborators` phone cores) returns `all` (every team number) and `hidden` (the ones registered in `zapp_internal_contacts`). `hidden` is removed from the `list-clients` rows and from global search, finance client badge and MCP counts; the rest of `all` stays in the client list marked "Interno" and is subtracted from client totals. `src/lib/internalClients.ts` + `useInternalClientIds` are the app-side path and `isInternalClientRecord` in `src/lib/zappInternalContacts.ts` covers client records. Why: a colleague's number registered as a client must not be counted or exported as a client, but the team still needs to find the record.
- Clínica Ryka usage: `sync-ryka-clinics` (daily cron + button) matches eligible clients by product-name substring, stores match in `client_ryka_provisions.ryka_response` and, when the Ryka API answers `action=clinic_usage`, one row per client/day in `client_ryka_usage_daily` (read-only, same-account RLS). The dashboard classifies with `src/lib/ryka/clinicUsage.ts`. Why: product names carry prefixes ("EC l …"), and usage history must come from Ryka, never be invented in ROY.
