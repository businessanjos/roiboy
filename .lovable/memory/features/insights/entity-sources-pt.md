---
name: Fontes de dados do construtor de visuais (Insights)
description: Entidades disponíveis no Insights seguem o modelo Pipedrive — Negócios, Leads (=Pessoas), Atividades e RoyZapp; Organizações não existem
type: feature
---

Entidades do construtor de visuais (Insights):
- Negócios (`deals`), Leads (`leads` — equivalente a "Pessoas" do Pipedrive), Atividades (`tasks`, nunca chamar de "Tarefas"), Produtos e Histórico de Vendas.
- RoyZapp: duas fontes — `royzapp` (tabela `zapp_conversations`) e `royzapp_messages` (tabela `zapp_messages`).
- "Organizações" não é usado e nunca deve ser criado.
- Fontes RoyZapp não aparecem no visual de Tabela (sem colunas definidas).
